# Job-board applications analysis

## Files
- `job_board_applications_analysis.ipynb`: reproducible analysis notebook.
- `job-board-applications.csv`: original assignment dataset.
- `cleaned_job_board_applications.csv`: cleaned dataset.
- `shortlisting_rate_by_steps.png`: chart for Question 2.
- `manager_note.txt`: approximately 200-word manager summary.

## Run
1. Install Python 3, pandas, numpy, matplotlib and Jupyter.
2. Keep all files in the same folder.
3. Open `job_board_applications_analysis.ipynb` and run all cells from top to bottom.

## Cleaning
Six exact duplicate application IDs were removed. Work-mode labels were standardised. Missing source values were labelled `unknown`; missing reply days were retained as missing because the brief defines them as no reply yet. No applicant source was guessed.
